## Overview

Zhorin language is a compressed, logic-driven communication system designed to describe states, actions, and outcomes with minimal redundancy.

It is not expressive. It is functional.

---

## Core Principles

Zhorin language is built on:

- Compression
- Clarity
- System alignment

It avoids:

- emotional framing
- metaphor
- ambiguity

---

## Absence of Deception Constructs

Zhorin language does not encode deception.

There are no direct equivalents for:

- lies
- trickery
- manipulation

Instead, inconsistencies are described as:

> Deviation from expected outcome within Mhekor (mek-or)

Only:

- Zholahukuhlan
- Uhlahukuhlan
- External civilizations

process these concepts fully.

---

## Sentence Structure

Zhorin communication follows:

> Subject → State → Action

Example:

- Human: “The Elder commands the fleet”
- Zhorin: “Okhen Mhekor zhan”

---

## Time Representation

Zhorin language does not rely on tense.

Time is indicated using markers:

- **ka** → past
- **ra** → future

Example:

- “Okhen zhan” → Elder commands
- “Okhen ka zhan” → Elder commanded
- “Okhen ra zhan” → Elder will command

---

## Plurality System

Zhorin do not use plural suffixes.

Instead:

- Context determines quantity
- **Mh-** indicates collective unity

Examples:

- Okhen → one or more Elders
- Mh-Okhen → Elder collective acting as one

---

## Functional Quantity

Rather than precise counting, Zhorin prioritize functional grouping:

- En (en) → one
- Tor (tor) → pair
- Khe (kheh) → few
- Var (var) → several
- Zhun (zhoon) → many
- Rakh (rahk) → overwhelming quantity

---

## Word Construction

Zhorin words are constructed using:

- Root meaning
- State markers
- Role markers

Common patterns:

- **-ii** → elevated state
- **-hri** → transformation
- **Ez- / E-** → entity embodiment
- **Mh-** → collective unity

---

## System Role

Zhorin language reinforces their worldview:

> Individuals are secondary. Systems are primary.

It ensures that:

- Communication remains aligned
- Interpretation remains consistent
- Deviation is minimized

---

## Limitation

The structure of the language restricts:

- conceptual expansion
- recognition of certain cognitive states

This limitation becomes visible through:

- Uhla
- Uhlahukuhlan
- Indhiirho

---

## System Implication

Zhorin language is not neutral.

It is:

> A constraint that shapes how reality is perceived and understood.
